# Print method for thingsvision_extractor objects

Displays basic information about the configured thingsvision extractor,
including the model name, source, and device. For full architecture, use
\`show_model()\`.

## Usage

``` r
# S3 method for class 'thingsvision_extractor'
print(x, ...)
```

## Arguments

- x:

  An object of class \`thingsvision_extractor\`.

- ...:

  Additional arguments (ignored).
