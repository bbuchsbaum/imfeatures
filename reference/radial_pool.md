# Radial centre/periphery pooling

Radial centre/periphery pooling

## Usage

``` r
radial_pool(breaks = c(0, 0.25, 0.5, 1))
```

## Arguments

- breaks:

  Increasing numeric breakpoints in \\\[0, 1\]\\ for normalized radius
  from the spatial centre. The default `c(0, 0.25, 0.5, 1)` yields three
  annuli.
