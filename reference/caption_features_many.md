# Batch caption feature extraction with progress

Batch caption feature extraction with progress

## Usage

``` r
caption_features_many(impaths, ..., .progress = interactive())
```

## Arguments

- impaths:

  Vector of image file paths.

- ...:

  Arguments passed to caption_features.

- .progress:

  Show progress bar.

## Value

A tibble with class \`imfeatures_feature_tbl\`.
